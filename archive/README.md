# Archive

This directory preserves the previous implementation of features that are deferred or superseded by the current RDZ specification.

- Nothing here is part of the build, the active source tree, or the test suite.
- Do not import from `archive/` in `src/` or `server/`.
- The old product spec is `docs/SPEC_v0.md`; deferred features are documented in `docs/FUTURE_SPEC.md`.

The archived code includes circles, circle stats, the ranked photo wall, voice notes, possession inventory, the reusable package build, and their tests. They are kept for reference only.
